---
title: The menu bar
description: What each menu in Tori's macOS menu bar holds, and why some items show no shortcut.
---

Apart from the standard macOS items (Undo, Copy, Minimize and the like), every
item from File to Window is an action from the command palette, under the same
name it has there and in the shortcut sheet (`Cmd+/`).

An item shows its shortcut only when Tori runs it wherever you are. Some keys
mean something else in one place: `Cmd+S` saves in the editor but stashes a
draft in the composer, `Cmd+,` in the agent picker opens that agent's
settings, and `Cmd+P`, `Cmd+L` and `Ctrl+-` stay with a program running in
the terminal. Those keys still work, but the menu leaves them out, because a
key shown in the menu bar is taken wherever focus is. The
[Keyboard shortcuts](/docs/workspace/keyboard-shortcuts/) page lists them all.

Choosing an item that has nothing to act on, such as **Save** with no
file open, shows a notice saying why rather than doing nothing.

## Tori

| Item | Keys |
| --- | --- |
| About Tori | |
| Settings... | |
| Check for Updates... | |
| Services, Hide, Hide Others | `Cmd+H`, `Cmd+Opt+H` |
| Quit Tori | `Cmd+Q`. Asks first, see [Quitting](/docs/daemon/#quitting) |

**About Tori**, also in the command palette, shows the version and the commit
the build came from. Click the version to copy it as `Tori <version>
(<commit>)`, the line to paste into a bug report. Below it are links to the
website, the docs, the release notes and GitHub, and **Check for Updates**,
which closes the dialog and runs the same check as the menu item.
